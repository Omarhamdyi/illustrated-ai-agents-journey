# Illustrated AI Agents Journey

My journey through [*An Illustrated Guide to AI Agents*](https://www.oreilly.com/library/view/an-illustrated-guide/9798341662681/) by Maarten Grootendorst and Jay Alammar.

After each chapter I:

1. Summarize it as visual notes in Excalidraw
2. Share the notes on LinkedIn together with one concept from the chapter
3. Add the notes and resources to this repo

This repo also holds **TinyAgent**, the agent the book builds step by step. I publish my implementation and the steps for each stage in [`tinyagent/`](tinyagent/).
